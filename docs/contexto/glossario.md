# Glossário - RightPoint

## Termos do domínio

| Termo | Definição |
| --- | --- |
| Análise de potencial | Avaliação de uma atividade econômica em uma região ou localização. |
| Atividade econômica | Tipo de operação comercial analisada, como padaria, restaurante ou barbearia. |
| CNAE | Classificação Nacional de Atividades Econômicas usada para identificar atividades exercidas por empresas. |
| Concorrente | Estabelecimento cuja atividade é igual, equivalente ou relacionada à atividade analisada e que se encontra na área considerada. |
| Densidade populacional | Relação entre o número de habitantes e a área de uma região. |
| Empreendedor | Usuário que consulta o potencial de abertura de um negócio. |
| Estabelecimento | Empresa existente identificada em fonte pública, geralmente por CNPJ. |
| Fator de análise | Informação normalizada que contribui positiva ou negativamente para o score. |
| Fonte de dados | Origem pública ou equivalente de indicadores e registros de empresas. |
| Indicador regional | Medida associada a uma região e a uma data de referência, como população ou renda média. |
| Justificativa | Explicação dos fatores que influenciaram o resultado de uma análise. |
| Localização | Ponto geográfico usado como centro de uma análise por raio. |
| Raio de análise | Distância máxima, em metros ou quilômetros, usada para delimitar a busca por concorrentes. |
| Região geográfica | Recorte territorial analisado, como bairro ou município. |
| Score | Nota entre 0 e 100 que representa o potencial comercial estimado. |
| Situação cadastral | Estado do registro de uma empresa na fonte oficial, como ativa, suspensa, inapta ou baixada. |
| Snapshot da análise | Cópia dos dados e fatores usados no momento do cálculo, preservada para consulta histórica. |

## Termos pendentes

- `nível de confiança`: A CONFIRMAR se será adotado para qualificar resultados com dados incompletos;
- `atividade equivalente`: A CONFIRMAR quais critérios relacionarão CNAEs ou categorias diferentes;
- `potencial comercial`: A CONFIRMAR quais faixas de score representarão potencial baixo, médio ou alto.
