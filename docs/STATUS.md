# Status de continuidade — RightPoint

Atualizado em 14/10/2026. Este arquivo registra o ponto de retomada entre escola, casa e trabalho. Antes de cada commit relevante, confira se ele ainda descreve o estado real do projeto.

## Como trabalhamos

- O usuário desenvolve o código na maior parte das vezes. O agente orienta com arquivos, trechos de código e comandos, e revisa o resultado quando solicitado.
- Para cada exercício de PHP/Laravel, o agente deve explicar para que serve a etapa no RightPoint, indicar o caminho exato do arquivo, fornecer o código necessário e mostrar onde colocá-lo e como executar e validar, em passos pequenos e adequados a iniciante. Revisar o código apresentado pelo usuário sem tratar a sugestão como implementação concluída; não assumir a edição do código sem pedido explícito.
- Ao finalizar uma etapa, registrar aqui o que **foi realmente feito**, as validações e pendências, para retomada em outra máquina, e indicar ao usuário o próximo passo concreto. Plano e sugestão não equivalem a etapa concluída.
- Não considere uma etapa concluída apenas porque ela foi sugerida nesta conversa. Verifique os arquivos, o Git e o banco do computador em uso.
- Consulte [AGENTS.md](../AGENTS.md), o [plano de implementação](./planos/implementacao-inicial.md) e o [procedimento para múltiplos computadores](./procedimentos/ambiente-multiplos-computadores.md) antes de mudanças relevantes.

## Retomada imediata em outra máquina

- Antes de atualizar o checkout, conferir `git status --short --branch`, arquivos locais e o `.env` sem expor seu conteúdo. O Git sincroniza código e documentação, mas não o banco MySQL nem `vendor/`; seguir o [procedimento de múltiplos computadores](./procedimentos/ambiente-multiplos-computadores.md).
- O comando `Right_Point/app/Console/Commands/ImportarMunicipiosRj.php` agora valida e grava os municípios usando `Municipio::upsert` dentro de `DB::transaction`. Em 13/10/2026, duas execuções reais no MySQL/MariaDB do XAMPP deixaram 92 municípios do RJ, sem duplicatas e com os mesmos IDs e datas de criação entre as execuções.
- Em outro computador, confirmar a conexão do `.env`, consultar `php artisan migrate:status` e aplicar somente migrations pendentes. Dentro de `Right_Point/`, executar `php artisan ibge:importar-municipios-rj` para carregar ou atualizar o banco local; repetir e conferir os 92 códigos do RJ. O comando altera dados: o Git não transfere as linhas já importadas. Não usar `migrate:fresh` ou apagar tabelas.
- O protótipo visual foi implementado em 14/10/2026 e aguarda teste manual no navegador com rede; detalhes no primeiro item da seção seguinte. A importação da população continua pendente. A demonstração não apresenta score nem concorrência como calculados enquanto faltarem cobertura CNPJ, fórmula aprovada e dados integrados. Propriedade/autenticação continua a decidir antes de persistir perfis compartilhados.
- Seeders para cadastros fixos ou dados de demonstração ficam em **prioridade baixa** por decisão do usuário em 14/10/2026; não bloqueiam a validação e futura importação da população.
