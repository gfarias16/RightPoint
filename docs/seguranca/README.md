# Segurança

## Estado atual

O sistema ainda não possui implementação nem dados reais. Esta seção registra premissas para evitar que decisões futuras ignorem riscos básicos.

## Premissas iniciais

- usar somente dados públicos ou dados fornecidos com base legal adequada;
- não armazenar credenciais nos documentos ou no código;
- coletar apenas os dados necessários para a análise;
- validar toda entrada recebida da interface e de fontes externas;
- registrar a origem dos dados sem expor informações sensíveis;
- definir autenticação e autorização antes de associar históricos a usuários;
- revisar os termos de uso das fontes antes de automatizar a coleta.

## Pontos a confirmar

- necessidade de cadastro de usuário;
- período de retenção do histórico;
- existência de dados pessoais além dos cadastros públicos empresariais;
- fontes e licenças permitidas para uso acadêmico e eventual uso real.
