# Decisões Arquiteturais

Esta pasta registrará decisões técnicas relevantes que precisem manter contexto, justificativa e consequências ao longo do projeto.

## Estado atual

Ainda não há decisão arquitetural aprovada. Os documentos em `docs/arquitetura/` são modelos conceituais e não definem tecnologia.

## Quando criar um registro

Crie uma decisão quando o grupo escolher, por exemplo:

- tecnologia de aplicação ou banco de dados;
- estratégia de integração com fontes públicas;
- fórmula e versionamento do score;
- forma de preservar snapshots históricos;
- abordagem para cálculo geográfico.

## Modelo de registro

Use nomes como `0001-titulo-da-decisao.md` e inclua:

1. contexto e problema;
2. alternativas consideradas;
3. decisão e justificativa;
4. consequências e riscos;
5. possibilidade de revisão ou reversão.
